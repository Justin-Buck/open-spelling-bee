# Picture clues

Put each puzzle's picture clue here, named after its pangram:
`telephone.png`, `laundry.jpg`, and so on (png, jpg, jpeg, webp or svg).

Then run `node scripts/filter-puzzles.mjs` so `src/words/puzzles.json`
picks it up, and bump `cacheName` in `src/pwa/serviceWorker.js` before you push.
